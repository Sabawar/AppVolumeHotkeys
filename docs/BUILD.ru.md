# Инструкция по сборке и использованию

## Требования

- Windows 10 или новее
- .NET SDK 8 или новее для сборки

Опубликованная версия self-contained, поэтому пользователю не нужно отдельно устанавливать .NET.

## Сборка

Из корня проекта:

```powershell
dotnet publish AppVolumeHotkeys.csproj -c Release -r win-x64 --self-contained true -o publish-self-contained /p:PublishSingleFile=true /p:IncludeNativeLibrariesForSelfExtract=true /p:EnableCompressionInSingleFile=true
```

Готовый файл появится тут:

```text
publish-self-contained\AppVolumeHotkeys.exe
```

## Использование

1. Запусти `AppVolumeHotkeys.exe`.
2. Включи звук в нужном приложении хотя бы один раз.
3. Обнови список аудиосессий.
4. Добавь процесс приложения в цели.
5. Отметь одно или несколько приложений галочками.
6. Назначь три общих бинда.

Три бинда применяются ко всем отмеченным приложениям:

- Увеличить громкость
- Уменьшить громкость
- Mute/unmute

## Специальная кнопка управления звуком

Включи `Специальная кнопка управления звуком управляет активным отмеченным приложением`, чтобы перехватывать стандартные Windows-клавиши громкости. Управляться будет только активное окно, если его процесс отмечен в списке целей.

## Портативные файлы

Файлы лежат рядом с exe:

- `settings.json`
- `keyboard.log`

## Автозапуск

Автозапуск использует Run-ключ текущего пользователя Windows и запускает приложение с аргументом `--minimized`.
